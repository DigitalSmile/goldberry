## 3. Reproducing a lane here

The Java lane, for the classes above (`docs/testing.md` §5 has the whole suite):

```sh
./gradlew :widgets:test :example:test :media:test --continue \
  -Pgoldberry.skipNative=true -Dgoldberry.native.library=/nonexistent/libgoldberry.so
```

The Media lane adds `-Pgoldberry.media.required=true`, with FFmpeg built by
`:media:ffmpegBuild`. Before the fixes: 3, 8 and 54 failures, the CI numbers
exactly. After: 0, with 3, 1 and about 20 skipped where the library is needed.
