Build fast, lightweight desktop apps in no time.

Goldberry is an open-source, declarative UI toolkit for Java 25+. A window is three lines, a screen is a KDL file that reloads while it runs, and the same code runs as a plain jar on any JDK or compiles with GraalVM into one native binary. No JNI, no bundled web engine. Apache 2.0.

Read the book

Easy setup, instant window

Any JDK 25+, one BOM, and a window on screen before the coffee is poured. GraalVM is a third step, and an optional one.

1 · Build file

Add the dependency

The BOM pins the version; the goldberry artifact brings common, natives, core and widgets. The native library arrives as classifier jars, one per platform you run on.

2 · Plain Java

Open a window on any JDK 25+

Three lines. No backend to name, no event loop to write. Runs as an ordinary jar; nothing to install beyond the jars themselves.

3 · Optional: GraalVM

Compile to one native binary

The same application, compiled ahead of time with GraalVM native image. One executable, the native library inside it, no JDK on the user's machine.

      Widgets are the heart of the toolkit

      Styled in CSS, the real one

      Variables, cascade, pseudo-classes and transitions, laid out by Yoga flexbox. A stylesheet names tokens, never colours, and reloads while the application runs. The class on a KDL node is the whole contract with it.
