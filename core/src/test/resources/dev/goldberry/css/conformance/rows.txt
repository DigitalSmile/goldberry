# The CSS conformance table: what the stylesheet engine does with each probe.
#
# kind | css | outcome | plan [| reference]
#
#   kind      decl (one declaration) or sheet (a whole sheet's text)
#   outcome   decl:  APPLIED, IGNORED, DROPPED, UNKNOWN
#             sheet: PARSED, REFUSED
#             either: MALFORMED
#   plan      - for what the subset has; the docs/css-plan.md item that changes
#             the row (CSS-NN); by-design; or unplanned
#   reference an IGNORED row's declaration that it comes out equal to
#
# Grouped as docs/css-support-2026-10-10.md groups its gaps. When a plan item
# lands, move its rows to their new outcome, and their plan column to - once
# the feature is whole.
